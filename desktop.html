Run CList on Your Own Computer

CList normally runs in your browser from clist.mooc.ca. You can also run the exact same application entirely on your own computer, with no website involved — useful if you'd rather not depend on any particular site staying online, or if you just want CList available offline. There are two ways to do this.

Part 1 — Run CList as a self-contained app

This runs CList from a small local server on your own machine, the same way it runs when hosted — just double-click to start it. For each platform there are two downloads: one that also bundles a LocalRSS feed-reading backend, so it works out of the box with no separate setup, and a plain one for anyone who already runs their own LocalRSS (or doesn't use it at all).

Windows

Download CList + LocalRSS Recommended. Includes a local LocalRSS backend — works right away, no extra install.
Download CList Plain build. Use this if you already run your own LocalRSS, or don't need it.

macOS

Download CList + LocalRSS Recommended. Includes a local LocalRSS backend — works right away, no extra install.
Download CList Plain build. Use this if you already run your own LocalRSS, or don't need it.

Linux

Download CList + LocalRSS Recommended. Includes a local LocalRSS backend — works right away, no extra install.
Download CList Plain build. Use this if you already run your own LocalRSS, or don't need it.

Double-click the downloaded app — it starts a local server on your own computer and opens CList in your default browser automatically. All downloads are also listed on the Releases page.

Once it opens, CList works exactly as it does on the hosted version: register or log in with a regular account, or click Change Account Server in the login pane to switch to Local storage instead, which keeps everything only on this computer. See how this works for the short version of why it needs a local server at all.

Prefer to build it yourself instead of downloading a prebuilt app? Get the source from github.com/Downes/CList and run the build script for your platform (build-windows.ps1, build-macos.sh, or build-linux.sh) — add -WithLocalRSS / --with-localrss to bundle LocalRSS too. This requires Python 3, or you can just run python3 launcher.py directly without building a standalone app at all.

Part 2 — Save the files and run them directly

This is the simplest option: no install, nothing to run, no Python required. You just save a folder to your computer and open a file in your browser.

  • Download the CList files (ZIP)
  • Unzip it anywhere on your computer
  • Open index.html from that folder in your browser (double-click it, or drag it into a browser window)

CList opens and works the same way as the hosted version: register or log in with a regular account, or click Change Account Server in the login pane to switch to Local storage instead, which keeps everything only on this computer.
